# HoneyChain Project Requirements

## A. Project Requirements
* OS: Windows / Linux / macOS
* Git

## B. Backend Requirements
* Python 3.11+
* PostgreSQL 16
* Dependencies: See `backend/requirements.txt` or `requirements.txt` at root.

## C. Mobile Requirements
* Flutter SDK (latest stable)
* Dart SDK
* Android Studio / Xcode
* Android SDK

## D. Blockchain Requirements
* Node.js 20+
* npm
* Hardhat
* Solidity

## E. IoT Requirements
* ESP32
* Mosquitto MQTT Broker

## F. AI/ML Requirements
* Requirements as defined in `ai_ml/` directory.

## G. Environment Variables
See README.md for `.env` template.

## H. Installation Commands
* Backend: `pip install -r backend/requirements.txt`
* Blockchain: `npm install` (in `blockchain/`)
* Mobile: `flutter pub get` (in `mobile_app/`)

## I. Runtime Requirements
* PostgreSQL, Mosquitto, Backend, Blockchain Node must be running for full flow.

## J. Testing Requirements
* `pytest` for backend
* `hardhat test` for blockchain
* `flutter test` for mobile
