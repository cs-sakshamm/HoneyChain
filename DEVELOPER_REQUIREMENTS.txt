# ------------------------------------------------------------------------------
# 1. DEVELOPER WORKSTATION HARDWARE & OS PREREQUISITES
# ------------------------------------------------------------------------------
Operating System:
  - Linux: Ubuntu 22.04 LTS or newer (Recommended)
  - macOS: macOS Monterey 12.0 or newer (Apple Silicon M-series or Intel x86_64)
  - Windows: Windows 10 (Build 19041+) / Windows 11 with PowerShell 7+ or WSL2

Hardware Minimums:
  - Processor: Quad-core 64-bit CPU (x86_64 or ARM64)
  - RAM: 16 GB minimum recommended (8 GB absolute minimum for running emulators/Docker)
  - Storage: 30 GB available free disk space (SDKs, Docker images, dependencies)
  - Network: Unrestricted local ports (3000, 5000, 8000, 8545, 1883)

# ------------------------------------------------------------------------------
# 2. CORE RUNTIME ENVIRONMENTS & TOOLCHAINS
# ------------------------------------------------------------------------------
The following runtimes and toolchains must be installed and accessible on PATH:

A. Version Control:
   - Git: >= 2.34.0
   - Branching Model: Git flow / Feature branch workflow (feature/*, fix/*)

B. Node.js & JavaScript Toolchain:
   - Node.js: >= 18.0.0 LTS (Node 20.x recommended)
   - npm: >= 9.0.0 (or pnpm >= 8.0.0)
   - TypeScript: >= 5.4.5 (global or project-local)

C. Python Environment:
   - Python: 3.10.x or 3.11.x (Python 3.11.8 recommended)
   - Package Manager: pip >= 23.0
   - Virtual Environments: venv or virtualenv strictly required per subsystem

D. Flutter & Mobile Development:
   - Flutter SDK: >= 3.0.0 < 4.0.0 (Channel stable)
   - Dart SDK: >= 3.0.0 < 4.0.0 (Bundled with Flutter)
   - Java Development Kit (JDK): OpenJDK 17 LTS
   - Android SDK: Android Build Tools (API 34), Platform Tools
   - iOS (macOS only): Xcode 15+ with Command Line Tools and CocoaPods 1.14+

E. Blockchain & Smart Contract Toolchain:
   - Hardhat: ^3.16.0 / @nomicfoundation/hardhat-toolbox
   - Solidity Compiler (solc): ^0.8.20
   - Ganache CLI / UI: >= 7.9.2 (Local EVM execution on port 8545)
   - Ethers.js: ^6.17.0

F. IoT & Embedded Firmware:
   - Target Hardware: Espressif ESP32 Dev Module (ESP-WROOM-32)
   - Toolchain: PlatformIO Core/IDE or Arduino IDE 2.3+
   - Board Package: esp32 by Espressif Systems (v2.0.14+)
   - Serial Drivers: CP210x or CH340 USB-to-UART bridge driver

G. Message Broker & Containerization:
   - Docker Engine: >= 24.0.0
   - Docker Compose: >= v2.20.0
   - Eclipse Mosquitto: >= 2.0.0 (Broker on port 1883)

# ------------------------------------------------------------------------------
# 3. REPOSITORY SUBSYSTEM STRUCTURE & LOCATIONS
# ------------------------------------------------------------------------------
HoneyChain is organized into clearly decoupled modules:

/backend          -> Python FastAPI REST APIs + Node.js/TypeScript KYC & Auth services
/blockchain       -> Solidity smart contracts, Hardhat test suites & deploy scripts
/mobile_app       -> Flutter mobile application for Harvester, Collector, Lab, Packaging
/iot              -> ESP32 firmware code, sensor schematics & MQTT publication protocol
/mosquitto        -> Eclipse Mosquitto MQTT broker configuration & access controls
/shared           -> Cross-subsystem JSON schemas, data models, and cryptographic types
/docs             -> Technical specifications, audit reports, and architecture guides
/ai_ml            -> AI/ML anomaly detection models & MQTT processors (*PROTECTED MODULE*)

# ------------------------------------------------------------------------------
# 4. SUBSYSTEM SETUP & DEVELOPER QUICKSTART
# ------------------------------------------------------------------------------

A. Backend (FastAPI & Python Services):
   1. Navigate to /backend
   2. Create a virtual environment:
      python -m venv venv
      source venv/bin/activate  (Linux/macOS)  OR  .\venv\Scripts\Activate.ps1 (Windows)
   3. Install Python requirements:
      pip install -r REQUIREMENT.txt
   4. Configure environment:
      Copy .env.example to .env and configure DATABASE_URL, RPC_URL, and secrets.
   5. Launch FastAPI development server:
      uvicorn main:app --reload --host 0.0.0.0 --port 8000

B. Backend (TypeScript / Express / Prisma Services):
   1. In /backend:
      npm install
   2. Generate Prisma ORM client:
      npx prisma generate
   3. Run database migrations:
      npx prisma migrate dev
   4. Start Node.js service:
      npm run dev  (Starts service on port 3000)

C. Blockchain & Smart Contracts:
   1. Navigate to /blockchain
   2. Install dependencies:
      npm install
   3. Start local EVM test node (Ganache or Hardhat):
      npx hardhat node  (or ganache --port 8545)
   4. Compile contracts:
      npx hardhat compile
   5. Run test suite:
      npx hardhat test
   6. Deploy contracts locally:
      npx hardhat run scripts/deploy.js --network localhost
   7. Note the deployed contract address and update backend/mobile .env configurations.

D. Mobile App (Flutter):
   1. Navigate to /mobile_app
   2. Install Flutter packages:
      flutter pub get
   3. Check development environment:
      flutter doctor
   4. Run unit and widget tests:
      flutter test
   5. Run on connected device or emulator:
      flutter run

E. IoT & Mosquitto Telemetry Broker:
   1. Start Mosquitto via Docker Compose:
      docker compose up -d mosquitto
   2. Verify broker is listening on port 1883:
      mosquitto_sub -h localhost -t "honeychain/#" -v
   3. Flash ESP32 firmware using PlatformIO or Arduino IDE with DHT22 & HX711 libraries.

# ------------------------------------------------------------------------------
# 5. ENVIRONMENT VARIABLES & SECRETS SPECIFICATION
# ------------------------------------------------------------------------------
Developers must maintain a valid `.env` file in `backend/` based on `backend/.env.example`:

Key Variables:
  PORT                     Default: 3000 (Express) / 8000 (FastAPI)
  NODE_ENV                 development | production
  DATABASE_URL             SQLite ("file:./dev.db") or PostgreSQL connection string
  AADHAAR_PROVIDER         sandbox | signzy | hyperverge | digio (Default: sandbox)
  OTP_PROVIDER             sandbox | 2factor | msg91 (Default: sandbox)
  BLOCKCHAIN_RPC_URL       http://127.0.0.1:8545 (Local Ganache / Hardhat node)
  CONTRACT_ADDRESS         Hex string (0x...) of deployed HoneyChain smart contract

# ------------------------------------------------------------------------------
# 6. DEVELOPER CODING CONVENTIONS & QUALITY GATES
# ------------------------------------------------------------------------------
- Python Code: PEP 8 compliant, type-hinted, formatted with Black/Ruff.
- TypeScript: Strict type-checking enabled (`tsconfig.json`), no untyped `any`.
- Flutter/Dart: Adhere to `flutter_lints`, avoid hardcoded strings, use AppConstants.
- Smart Contracts: Solidity 0.8.20+, use OpenZeppelin standards, revert on failed checks.
- Git Commits: Follow Conventional Commits format (feat:, fix:, docs:, chore:, test:).

# ------------------------------------------------------------------------------
# 7. STRICT ISOLATION & SECURITY POLICY: AI/ML SUBSYSTEM
# ------------------------------------------------------------------------------
CRITICAL REPOSITORY RULE FOR ALL DEVELOPERS:
- The `ai_ml` directory contains specialized machine learning models, telemetry
  isolation forests, datasets, and MQTT streaming processors.
- Under NO circumstances should general features, backend refactorings, or
  documentation updates touch, modify, rename, delete, or move files in `ai_ml`.
- Any integration with AI/ML must happen strictly via public APIs, MQTT topic
  contracts, or shared schema definitions without altering internal AI/ML code.
